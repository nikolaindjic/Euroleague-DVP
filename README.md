# EuroLeague DvP

- **Run locally:** `python -m http.server 8000` in this folder, open http://localhost:8000. Test: `node check.mjs`.
- **Add a round:** open "Import a round", pick the Excel export, paste fixtures (`PAR-DUB`, one per line), Import, then **Download data.json** and replace the file here.
- **Deploy:** push this folder to GitHub Pages, or drag it onto Netlify Drop. No build step.
